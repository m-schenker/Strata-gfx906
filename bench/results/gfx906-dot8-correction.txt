# what it means
#  - "hi/lo" splits the 8-bit activation into two base-16 digits (h = (q8+8)>>4, l = q8-16h).  Both
#    digits are 4-bit two's complement for every integer q8, so nothing is rounded twice and the
#    integer result is IDENTICAL to the dp4a arm - the error column proves it (0.552/0.556/0.554 on
#    both).  Two dot8 passes over the same weight nibbles therefore give 8-bit accuracy at 2x the
#    throughput of dp4a where the ALU is the limit (16 groups), and a wash where HBM is (8 groups).
#  - the rounded-residual variant ("correction") is cheaper at 8 and 16 groups but ends at 0.81-0.86 %
#    error: the residual is itself 4-bit quantised, so it recovers most of the loss, not all of it.
#  - the partial dial (1/4, 2/4 of K) is a LOSS, not a saving: lanes diverge on the strided
#    b&3 < CORR test, and the error only falls as sqrt(1-f) because the residual noise is white.
#    Ran at 8/16/32 groups: 0.0258-0.0999 ms for 8.5-8.9 % error.  Not worth a column.
#  - dp4a needs the nibble unpack (2 masks per 8 values) that both dot8 arms skip; that unpack is
#    the entire difference at 16 groups, where the kernel is ALU-bound.
