# 0.2.15 engine wedges the GPU at kernel-module load on MI50 (this box) — blocks every suite round

Box: 4x Instinct MI50 32GB (gfx906), kernel 6.12.0-211.68.1, 125 GiB RAM, AlmaLinux 10.2.
Engine: fork gfx906-kernel-tuning (Strata 0.2.15 / engine 0.1.61), IQ4_XS pack (native IQ pack), 1 card.

Reproduced with BOTH runtime stacks:
  * TheRock 10.3.0a20261027 (the PR's Dockerfile runtime image)
  * the distro ROCm 7.1.1 (clang 20, rocBLAS 5.1.1) — the stack llama-rocm-docker:0.2 serves with

An earlier, different capture (TheRock, during prefill init) showed the same tail through
`hipMemcpyToSymbol -> hsa_executable_freeze -> InvalidateCodeCaches -> ExecutePM4`.

## How it presents

1. **Startup, 200 K context**: 5 of 6 configurations hung before READY (last line "the prompt path borrows
   N CUDA0 cache slots (x GiB)", or "session is up (engine 0.1.61)").  `--max-context 32768` starts in 20-25 s.
2. **Mid-request**: after "prefill: the GGUF experts are N% in the page cache; the stager takes the RAM profile",
   the engine spins at 100 % CPU with the GPU idle.
3. **Verify window**: a 12-token MTP lookup window "never finished on the GPU (#267); restart the engine" — the
   server kills and restarts, the request returns HTTP 503 after ~80 s.
   The diagnostic block printed with it: "verify window (last window ...): 12 tokens at position 0, host at layer
   step 1; the GPU rang 2; flags: served 0, plan (A) 0, copies (B) 0".

## What made a single request possible

    STRATA_WINDOW_WARM=0        # skip the pre-READY verify-window warm-up (it is the first place that hangs)
    --lookup-max-t 0            # no 12-token prompt-lookup window (the MTP windows stay at <= --spec)
    --max-context 32768         # 200 K hangs at startup on this box
    --prefill 8192              # fixed chunk (the auto 32768 plan hangs the same way)

With that: one request completes, the **second request of the same shape** returns 503.  Single-request samples
(IQ4_XS, 1 card, 32 K, 18000 expert slots): 4 058-token prompt -> PP 184.0 tok/s, 24 generated at 28.9 tok/s;
61-token chat -> 17.8 tok/s decode (first request, graph build included).

## Why this is a regression and not the card

The same box serves the same model and pack with Strata **0.2.1** + mi50-port (4 cards, layer split 12,24,36,
800 K context) for days.  Nothing in patches 0003-0009 touches module loading.

## Not tried

A different TheRock nightly (the Dockerfile's ROCM_VERSION is a build arg), HIP graph capture off for the verify
path (`--no-capture` needs `--no-pool`, which silently drops the routed experts), and rocprof (the image has none).
